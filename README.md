# پورتفولیو زهراسادات یعقوبی

وب‌سایت شخصی برای معرفی سوابق، مهارت‌ها، پروژه‌ها و زمینه‌های پژوهشی زهراسادات یعقوبی. این پروژه با HTML، CSS و JavaScript خام ساخته شده و از زبان فارسی و انگلیسی، چیدمان راست‌به‌چپ، پوستهٔ روشن و تیره و نمایش واکنش‌گرا پشتیبانی می‌کند.

[مشاهده دمو](https://zsyh8080-dotcom.github.io/Portfolio-task2-2/) · [مشاهده کد منبع](https://github.com/zsyh8080-dotcom/Portfolio-task2-2) · [لینکدین](https://www.linkedin.com/in/zahra-yaghoubi-17691013)

## معرفی

صفحهٔ اصلی شامل معرفی، مهارت‌ها، تجربه، تحصیلات، پروژه‌های منتخب، مسیر پژوهشی و راه‌های ارتباطی است. صفحهٔ پروژه‌ها نمونه‌کارها را بر اساس دسته‌بندی نمایش می‌دهد و صفحهٔ پژوهش به ایده‌ها و روش اجرای طرح‌ها اختصاص دارد.

## امکانات

- طراحی واکنش‌گرا برای گوشی، تبلت و لپ‌تاپ
- پشتیبانی از زبان فارسی و انگلیسی
- پوستهٔ روشن و تیره با ذخیرهٔ انتخاب کاربر
- جست‌وجوی داخلی و منوی ناوبری برای بخش‌های سایت
- دکمهٔ بازگشت به بالای صفحه
- فیلتر پروژه‌ها و نمایش گواهی‌ها
- انیمیشن‌های سبک و نمودارهای تعاملی
- استفاده از فایل‌های محلی بدون نیاز به کلید یا سرویس خارجی

## اجرای محلی

این پروژه به فرایند build نیاز ندارد. برای اجرای محلی، در ریشهٔ پروژه یکی از دستورهای زیر را اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس آدرس زیر را در مرورگر باز کنید:

```text
http://localhost:8000
```

## نگهداری و توسعه

محتوای متنی و ترجمه‌ها در فایل‌های HTML و `data/i18n.json` قرار دارند. اطلاعات پروژه‌ها در `data/projects.json` نگهداری می‌شود و فایل‌های مربوط به ظاهر و چیدمان در پوشهٔ `css` قرار گرفته‌اند. تصاویر، فونت‌ها و گواهی‌ها در پوشهٔ `assets` و رزومه در `assets/documents` قرار دارد. اطلاعات کتابخانه‌های محلی در `assets/vendor/README.md` ثبت شده است.

## مجوز و منابع

فایل‌های مجوز کتابخانه‌ها و منابع استفاده‌شده در پوشهٔ `LICENSES` نگهداری شده‌اند. تصاویر شخصی، گواهی‌ها، رزومه و محتوای حرفه‌ای این پروژه متعلق به صاحب آن‌هاست.
